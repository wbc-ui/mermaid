# Changelog

## 3.0.0-rc.2

- Version bump for coordinated WBC v3 release candidate (npm `next`).

## 3.0.0-rc.1

- Vue 3 component and plugin API.
- Reactive Mermaid rendering with stale-result protection and unique render IDs.
- Inline, remote-file, local-context, flowchart-object, and sequence-object sources.
- Per-instance configuration with a secure `strict` default.
- `load`, `rendered`, `ready`, and `error` lifecycle events.
- Fetch cancellation, timeout control, accessibility labels, and standalone rendering.
- Optional `wbcObj` composition through `@wbc-ui/core`.
- `asWbc` for rendering flowchart-node and sequence-participant labels as live WBC content.

Release-candidate APIs may still receive feedback-driven refinements before `3.0.0`.
